Pasar los siguientes números a las bases indicadas usando propiedad de
potencia o raíz de base.

a. 75]8 ... ]16 b. BCD,EF]16...]2 c. 2211]3... ]9 d.1000,01]2...]8 e.1001]2....]16

a. 75 debo pasarlo de base 8 a base 2  
7 en base 2 = 111  
5 en base 2 = 101  
75 = 111101  
pasamos de base 2 a base 16  
1101 = 13 = D  
0011 = 3  
111101 = 3D  
75 base 8 = 111101 en base 2 = 3D en base 16  
<br>
b. BCD,EF debo pasarlo a base 2

C en base 2 = 1100  
D en base 2 = 1101  
E en base 2 = 1110  
F en base 2 = 1111  
101111001101,11101111 base 2  
BCD,EF base 16 = 101111001101,11101111 base 2

233031,3233  
si quisieramos en base 8 quedaria
5715,736, si no alcanzan los decimales agregamos un 0 (por ej, 11 con 3 digitos seria 110)
